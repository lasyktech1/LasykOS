# LasykOS
Welcome to the official repository of LasykOS! This is a custom command-line interface program completely rewritten from scratch in C++. It is optimized to run on old, weak computers.

## 🛠 What the project consists of:
* Program Base: Written in C++ (works on both Windows and Linux).
* Graphics Engine: Lasyk MatrixVision Core (written in C++, converts images into text symbols).
* Additional Programs: Written in Python 3 (integrated games and tools).
* Size: The entire archive weighs only about 6 KB due to clean code optimization.

## 📥 How to download:
All program files, including the snake.py game and timetools.py clock, are packed inside a single ZIP archive in this release.
